# Changelog

## 1.0.0

- Capture tasks in the TickTick Inbox with the `ttn` keyword.
- Optional list and priority selection via modifiers.
- Lists come from the TickTick Mac app; nothing is cached in the workflow.
- Universal Action for selected text.
- Open Inbox, Today, or Next 7 Days with `tti`, `ttt`, and `tt7`.
